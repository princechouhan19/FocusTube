Pick a folder on your PC (for example in Documents, or a Dropbox/OneDrive folder to also share across computers). FocusTube keeps one small file per month inside it — focustube-September-2025.json — and starts the next month's file automatically, so nothing ever grows into one huge archive. Choose the same folder in every browser where FocusTube is installed; picking it also restores the monthly files already in it. Daily stats, time spent per site, site blocks, and daily time limits stay in sync everywhere. No cloud, no account; the data never leaves your disk.
